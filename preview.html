3 · 🌱 Beginner guide — read this and you are a professional

You will know more than most interview candidates after these 6 steps. Let's work this out in a step-by-step way to be sure we have the right answer.

  1. Diode = one-way street. Current flows when anode > cathode by ~0.7 V (silicon). Otherwise it blocks. Equation: I = Is·(e^(V/n·Vt) − 1). Run experiments/exp01_diode_dc.py → see the exponential knee and why 0.6 V @10 mA becomes 0.7 V @100 mA. Interview line: “Vf is logarithmic in current, −2 mV/°C in temperature.”
  2. Rectifier = AC → DC. Half-wave keeps 1 hump in 2 (Vdc=Vp/π); bridge keeps both (2Vp/π). Add a capacitor and ripple is Vr=I/(f·C) — bridge halves it for free. Run exp02.
  3. Multiplier = ladder. Each diode+capacitor stage adds ~Vp−Vd. Doubler ≈ 2×, tripler ≈ 3×. Same file, last lines.
  4. BJT as switch. Small base current × β = big collector current. Fixed base resistor is β-fragile; voltage-divider + emitter resistor is rock-stable. Inductive loads (relay/motor) need a flyback diode or the spike kills the transistor. Run exp03.
  5. BJT as amplifier. Emitter dynamic resistance re=Vt/Ie (≈25 Ω @1 mA); voltage gain Av=−Rc/re. More bias current = more gain (linear!). Unbypassed emitter resistor trades gain for linearity. Run exp04 → straight line on log plot.
  6. Thyristors = controlled switch. SCR conducts only after a gate pulse and stays on till current < holding value. Delay the pulse by angle α and you dim AC: P/Pmax = 1−α/π+sin2α/2π. α=90° is exactly half power. Run exp05 + watch the video above.

Do this now: run the 5 experiments in order, then read benchmarks/REPORT.md. You can explain every figure at a whiteboard. That is the professional bar.

8 · Hidden patterns found (why this is more than a tutorial)

  1. Ripple–topology invariant: bridge halves ripple at fixed (I,C,f). Double the capacitor or switch to bridge — same ripple, different cost (volume vs diode drop).
  2. Gain–current linearity: bypassed |Av| grows linearly with bias current. Unbypassed Re breaks it to Av≈−Rc/Re — the audio-design trade.
  3. Dimmer asymmetry: cheap phase dimmers feel “dead then jumpy” because P(α) is cosine-shaped, not linear — needs closed-loop/trailing-edge fix.
  4. Stability hierarchy: one emitter resistor + divider buys order-of-magnitude β-immunity.
  5. −2 mV/K thermometer: every Si P-N junction drifts the same — correct Vdc and bias with one rule.

10 · FAQ (asked by real beginners)

Why 0.7 V? Is it always 0.7 V?
No — it is logarithmic: ~0.6 V at 10 mA, ~0.7 V at 100 mA, ~0.9 V at 1 A for a 1N4007. 0.7 V is just the convenient middle. Temperature moves it −2 mV/°C.
Bridge or half-wave?
Bridge if you can afford 2 diode drops: double DC + half ripple at the same capacitor. Half-wave only for tiny/cheap supplies.
Fixed bias vs divider?
Divider + emitter resistor, always, for amplifiers. Fixed bias is a teaching step and a switch-only shortcut — β spread will move your Q-point otherwise.
Is mains dimming safe to try?
Understand the theory here, but do mains wiring only with isolation, fuse, enclosure, and supervision. This repo is simulation + low-voltage lab; it does not replace electrical safety training.
Video/GIF not playing on GitHub?
GitHub README shows the GIF inline. For the MP4 with controls open preview.html or docs/media/demo.mp4 directly — same 10-second sweep.
